# 走査方向スプライン補間による欠損補完レポート

**作成日**: 2026-04-09  
**対象データ**: 50円玉裏面（実験装置で計測）  
**比較対象**: Keyence計測データ（260128_155543_50円玉_裏側_上.csv）

---

## 1. 背景と目的

本実験装置は、2D干渉縞画像を複数枚重ね合わせることで3次元面形状を復元する光学干渉計である。取得データには干渉縞と縞の間に空白（欠損）が発生し、断面方向に「ミルフィーユ状」の欠損パターンが存在する。

本レポートでは、走査方向（列方向）のスプライン補間によりこの欠損を補完し、Keyence計測データとの比較を通じてその有効性を検証する。

## 3. 欠損パターンの分析

### 3.1 「ミルフィーユ構造」の確認

実験装置データの列方向（走査方向）における有効/欠損のセグメント長を分析した。

| 指標 | 実験装置 | Keyence |
|---|---|---|
| 有効セグメント長（平均） | **3.6行** | 225.8行 |
| 有効セグメント長（中央値） | **2行** | 236行 |
| 有効セグメント長（最大） | 28行 | 261行 |
| 欠損ギャップ長（平均） | **7.5行** | 29.3行 |
| 欠損ギャップ長（中央値） | **3行** | 28行 |
| 有効セグメント数 | 14,862 | 308 |
| 欠損ギャップ数 | 15,503 | 437 |

実験装置データでは、有効データが平均2〜3行の非常に薄い層として存在し、その間に平均3〜7行の欠損ギャップが挟まる「ミルフィーユ構造」が確認された。これは干渉縞の各フリンジが1〜数行分の高さ情報しか提供せず、縞間の領域ではデータが取得できないことに起因する。

### 3.2 ギャップサイズの分布

| ギャップサイズ | 出現回数 | 割合 |
|---|---|---|
| 1〜3行 | 8,420 | 54.3% |
| 4〜8行 | 3,553 | 22.9% |
| 9〜15行 | 1,564 | 10.1% |
| 16行以上 | 1,966 | 12.7% |

全ギャップの **77.2%（1〜8行）が比較的小さいギャップ**であり、近傍の有効データから安全に補間できる範囲である。

## 4. 補間手法

### 4.1 方針

ギャップサイズに応じた段階的な補間戦略を採用し、形状の崩れを防止した。

| ギャップサイズ | 補間方法 | 理由 |
|---|---|---|
| **1〜3行** | 線形補間 | 直前・直後の有効値の内挿で十分な精度 |
| **4〜8行** | 局所スプライン補間 | 前後各5点を使用した3次CubicSpline。振動チェック付き |
| **9行以上** | 補間しない（スキップ） | 補間距離が長く形状が崩れるリスクが高い |

### 4.2 安全策

- **局所スプライン**: ギャップ前後の最大5点ずつのみを使用し、遠方のデータの影響を排除
- **範囲チェック**: 補間値が近傍の有効値範囲の ±30% を超えた場合、線形補間にフォールバック
- **外挿禁止**: 有効データの範囲外（列の先頭・末尾の欠損）は補間しない

## 6. 考察

### 6.1 成果

- **値の範囲が保持されている**（330.5〜948.0 → 変化なし）ことから、補間による形状の崩れは抑制できている
- 平均値も618.7→619.9とほぼ変化がなく、系統的なバイアスは発生していない
- 小さいギャップ（1〜8行）のミルフィーユ構造はほぼ解消された

### 6.2 Keyenceとの差

補間後の有効率は40.7%で、Keyenceの81.4%との間にまだ約40ポイントの差がある。残りの欠損は主に以下に分類される：

1. **大きなギャップ（9行以上）**: 干渉縞が全く検出できなかった領域。コイン端部や鏡面反射が強い領域に集中
2. **有効データ範囲外の欠損**: 列の先頭・末尾で、外挿を行っていない領域
3. **完全欠損行**: 走査末尾の192〜209行目は全セルが欠損

### 6.3 今後の改善案

| アプローチ | 期待効果 | リスク |
|---|---|---|
| 横方向（行方向）の補間追加 | 列方向で埋められなかった欠損の一部を補完 | 干渉縞の走査方向と直交するため精度は列方向より低い |
| 2D補間（RBF / griddata） | 点在する欠損も含めて面的に補間 | 計算コストが高い、大きな欠損領域で形状が崩れやすい |
| 大きなギャップの閾値緩和 | 有効率のさらなる向上 | 形状崩れのリスク増大 |
| 干渉縞の取得条件改善 | 根本的にデータ密度を改善 | ハードウェア・光学系の変更が必要 |

---

## 7. 結論

走査方向のスプライン補間により、干渉縞間の「ミルフィーユ状」欠損を**形状を保ったまま**補完できることが確認された。有効率は25.3%→40.7%に改善し、小ギャップ（1〜8行）の98.4%が解消された。Keyenceの81.4%には届かないが、残りの差は計測原理上の限界（大きな欠損領域）に起因しており、補間アルゴリズムの改善だけでなく計測条件の最適化も必要と考えられる。
