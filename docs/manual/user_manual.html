1このアプリでできること

1.1一言でいうと

装置で撮った干渉画像から 物の表面の凹凸（高さマップ） を求め、ブラウザで立体的に見ながら、 長さ・断面・高さのばらつき を測って保存するアプリです。 他の測定器（Keyence・WI5000 など）の高さマップ CSV を読み込んで、同じように見ることもできます。

1.2入力と出力

INPUT
干渉画像 または CSV
装置の撮影画像（data/row_data/）／高さマップ CSV／点群形式 CSV
PROCESS
計測（画像処理 or AI）
各画像の各行で縞の位置を求め、高さマップにする。CSV はそのまま表示
OUTPUT
表示・測定値・ファイル
3D/2D 表示、距離・寸法・断面、統計、CSV・PNG 画像、測定履歴

1.3作業の全体像（5 ステップ）

STEP 1
起動する
start_mac.sh を実行（2章）
STEP 2
データを出す
計測する／CSV を読み込む（3.1）
STEP 3
見る
回す・寄る・真上から見る（3.2）
STEP 4
測る・整える
距離・寸法・断面・統計、外れ値の除去（3.3〜3.4）
STEP 5
保存する
CSV・画像・測定履歴（3.5）

番号場所中身

2状態READY（待機中）／RUNNING（計測中）／COMPLETE（表示中）
3ツールバー3D/2D の切り替え、画像保存、ズーム、パン、回転、視点リセット（3.2・4章）
4視点のプリセット正面・側面・上面へ一発で向きを変える（3D のときだけ）

9情報チップ描画モード・エンジン、データの出どころ（CSV／デバイス）、ピッチ（1画素あたりの長さ）

2起動と終了

2.1動作環境

項目内容
PCMac（セットアップ済みのもの）。初めて使う PC は デプロイ手順 の「初回セットアップ」を先に済ませてください
ブラウザChrome を推奨（起動すると既定のブラウザが自動で開きます）
画面サイズ横 1440 × 縦 900 以上を推奨。狭い画面ではサイドパネルを隠すとプロットが広くなります
計測するとき装置の撮影画像を data/row_data/ に置いておきます（CSV を見るだけなら不要）

2.2起動する

  1. 「ターミナル」を開き、アプリのフォルダへ移動します。 
    % cd ~/Documents/optical-device-ui
  2. start_mac.sh を実行します。 
    % ./start_mac.sh

========================================

INFO:     Uvicorn running on http://0.0.0.0:8000
[2/2] フロントエンドを起動しています...
  VITE v7.x  ready
  ➜  Local:   http://localhost:5173/

  3. 数秒でブラウザが開き、次の画面が出れば起動完了です。右上の状態が READY になっていることを確かめてください。

ターミナルに GET /json/version ... 404 Not Found や GET / ... 404 Not Found と出ることがありますが、ブラウザの開発ツールなどが問い合わせているだけで、動作には関係ありません。

ブラウザが開かないときは、自分で http://localhost:5173 を開いてください。

2.3終了する

起動したターミナルで Ctrl + C を押します。ターミナルを閉じてしまったときは、別のターミナルで ./stop_mac.sh を実行すると止まります。

測定履歴（3.5）はブラウザに保存されているので、終了しても消えません。

3操作手順

3.1STEP 2：データを出す

データの出し方は 4 通りです。どれも右の 操作 タブから行います。

やりたいことボタン説明
装置で計測する▶ 計測開始data/row_data/ の画像を画像処理で解析します。ふだんはこちら
AI で計測するAI計測同じ画像を AI（学習済みモデル）で解析します。縞が見えにくい画像に強い
CSV を見るCSV読込高さマップ CSV（Keyence・WI5000・このアプリで書き出したもの）や点群形式 CSV を開きます
前回の AI 結果を見るマスク直近の AI 計測の結果（data/mask_result/）を開きます

装置で計測する

  1. アルゴリズム が「硬貨」になっていることを確かめます（押すと選択画面が出ます。いまは「硬貨」だけ選べます）。
  2. CPU / GPU を選びます。Mac では CPU を使います。
  3. ▶ 計測開始 を押し、確認で はい を押します。
  4. プロットに進み具合（工程・経過時間）が出ます。終わると自動で点群が表示されます。

中止 を押すと、区切りのよいところ（画像処理は工程ごと、AI は 1 枚ごと）で止まります。AI を中止したときは途中までの結果は残りません。

CSV を読み込む

  1. CSV読込 を押してファイルを選びます。
  2. 読み込むと面（Surface）で表示されます。ピッチ（1画素あたりの長さ）を確認してください。左下のチップに出ています。
  3. ピッチが違うときは、設定タブの「CSV（高さマップ）」で直します（5章）。目安は自社デバイス 10 µm、WI5000 約 37.4 µm、Keyence 約 32.9 µm です。

このアプリで書き出した CSV は、ファイル名にピッチと高さの単位が入っている（例: …_pitch10x10um_zum.csv）ので、読み込むと自動で設定に反映されます。

3.2STEP 3：見る

マウスでの操作

操作動き
左ドラッグ回転（ツールバーでパンを選んでいるときは平行移動）
右ドラッグ（three.js 表示）平行移動
ホイールズーム
カーソルを載せるその点の座標と高さを表示

ツールバー

よく使うのは次の 3 つです。

  • 2D（2）… 真上から見た表示。高さは色で読みます。寸法・断層（3.3）は 2D で使います。
  • パン（6）… 押すと左ドラッグが平行移動になります。もう一度押すと回転に戻ります。
  • 視点リセット（9）… 向き・ズーム・位置を最初に戻します。迷ったらこれ。

Plotly 表示のパンは、マウスの動きより大きく動きます。面が画面の外へ出て「消えた」ように見えたら、視点リセット（9）を押してください。

描画モードとエンジン（操作タブ「表示」）

項目選べるもの
描画モードSurface（面でつないで表示）／Point Cloud（点の集まりで表示）
エンジンPlotly（既定。軸と目盛り付き、ホバーで値が読める）／three.js（なめらかで速い。点群は高密度、面は CAD 風の陰影付きメッシュ）
軸軸と目盛りの表示・非表示
左右反転CSV では左右の鏡映。装置の計測データでは 深さの反転（意味が違うので注意）
自動回転3D をターンテーブルのように回し続けます（展示向け）
奥行きの強調点群のとき。奥行き方向の見た目だけを ×0.5〜×20 に伸ばします（値は変わりません）。ダブルクリックで ×1

3.3STEP 4：測る

操作タブの一番下「計測ツール」に 3 つの道具があります。押すとオン、もう一度押すとオフです。

距離（3D・2D）

  1. 距離 を押します。
  2. プロット上で 2 点をクリックすると、2 点を結ぶ線と距離が出ます。両端の座標はサイドパネルに出ます。

値の無いところ（黒く抜けた欠損）をクリックしても点は打てません。

寸法（2D）

  1. ツールバーで 2D にしてから 寸法 を押します。両矢印が 1 本出ます。
  2. 矢印の端をドラッグして、測りたい 2 点に合わせます。Shift を押しながらドラッグすると水平・垂直に固定できます。
  3. 距離と ΔX・ΔY がサイドパネルに出ます。＋ 寸法線を追加 で何本でも引けます（× で削除）。

断層（2D）— 断面を見る

  1. 2D にしてから 断層 を押すと、下に断面のパネルが出ます。
  2. プロット上で 2 点をクリックすると、その線に沿った断面が出ます。3 点目をクリックすると引き直しです。値の無いところにも点を打てます。
  3. 帯の幅 を選びます。線 は線の上の値だけ、200 µm〜1000 µm は線の両側の幅の中を全部集めて横から見ます（線＝中央値、薄い帯＝ばらつき P10〜P90）。

断面の上で長さと段差を測る： 断面パネル右上の 距離計測 を押し、グラフ上で 2 点をクリックすると、距離と Δ深さ（高さの差）が出ます。端の点はドラッグで動かせます。

統計（測定結果タブ）

測定結果 タブに、表示中のデータの統計が出ます。

項目意味
有効率値のある画素の割合。全体・中央50%×50%・中央面積50% の 3 通り
平均 ± 標準偏差高さの平均とばらつき
最小〜最大、P1〜P99高さの範囲（P1〜P99 は極端な 1% ずつを除いた範囲）
平面除去後 Sq / Sa傾きを引いたあとの凹凸の大きさ（二乗平均平方根 / 平均絶対値）

3.4STEP 4：整える（後処理）

操作タブの「後処理」で、飛び出た値（外れ値）を取り除いたり、抜けた行を埋めたりできます。元のデータは変わらないので、なし に戻せばいつでも元どおりです。

項目内容
外れ値の除去なし / 3σ / 4σ。数字が小さいほど多く取り除きます。迷ったら 3σ
外れ値の基準近傍（既定）… 周りと比べて突き出た点だけを取る。凹凸や段差は残る／全体 … 面全体と比べる。起伏の大きい面では本物の凹凸まで消えることがある
走査方向の補間走査の行の抜け（8 行以下）を周りの値で埋めます
補った画素の印埋めた画素をマゼンタ色で区別します（隠す で非表示）

補った値は実測ではありません。 精度を評価する（正解データと比べる）ときは、後処理を「なし」にした元のデータを使ってください。

3.5STEP 5：保存する

保存するもの操作中身
高さマップ（CSV）操作タブ CSV出力表示中の高さマップを µm で書き出します（左右反転・後処理も反映）。ファイル名にピッチと単位が入るので、読み込み直すと設定が戻ります
画像（PNG）ツールバー 3今の見た目を 1920×1080 の PNG（黒背景）で保存します
測定履歴自動計測・読み込みのたびに、最新 20 件をこのブラウザに自動で保存します

CSV のファイル名

書き出したファイル名の末尾で、条件がわかるようになっています。

付く文字意味
_pitch10x10umピッチ（列 10 µm × 行 10 µm）
_zum / _zpx高さの単位（µm／画素）
_hampel3 / _mad3外れ値の除去（近傍 3σ／全体 3σ）
_interp走査方向の補間あり

測定履歴を使う

  • 測定結果 タブの下のほうに履歴が並びます（図 13 右）。復元 で、そのときの表示に戻せます。
  • 名前をクリックすると名前を変えられます。削除 で 1 件、すべて削除 で全部消します。
  • 履歴は このブラウザの中だけ に保存されます。別の PC やブラウザには引き継がれないので、残したい結果は CSV で書き出してください。

6結果を読むときの注意

有効率は「どの範囲で」を必ず添えてください。 全体・中央50%×50%・中央面積50% で大きく違います（例: 1円玉の裏で 34% / 73% / 57%）。

  • 細かい粗さ（Ra・Sa が数 µm 以下）は測れません。 深さの分解能に対して抽出のノイズが約 0.26 µm あるためです。面の形・うねり（数十 µm 以上）を見る用途です。
  • 補った値・正解データで埋めた値は実測ではありません。 精度の評価には後処理前のデータを使います。
  • 欠損の多いデータほど誤差が小さく見えます。 手法どうしを比べるときは、両方に値がある所だけで比べます。
  • 表示は間引いています。 大きなデータは見た目だけ粗くしています。断面・統計・CSV 出力は元の細かさで計算しています。
  • 装置で計測したデータでは、左右反転は深さの反転 です（CSV の左右反転とは意味が違います）。

7困ったとき

症状確認すること・対処
表示が消えた・どこかへ行ったパンや回転で画面の外へ出ただけです。ツールバーの 視点リセット（9）を押してください。パンを使い終わったら、パンのボタンをもう一度押して回転に戻しておきます
「バックエンドに接続できませんでした」と出るバックエンド（計測を受け持つ部分）が動いていません。ターミナルで start_mac.sh が動いているか確かめ、止まっていれば起動し直してください（2.2）
ブラウザが開かない自分で http://localhost:5173 を開いてください
ターミナルに 404 Not Found が出る問題ありません（2.2 のメモ）
計測がなかなか終わらない画像の枚数が多いと数分かかります。進み具合の工程と経過時間を見てください。やめるときは 中止
長さ・寸法がおかしいピッチ（CSV）や µm/pix（デバイス）の設定を確かめてください（5章）。左下のチップに今の値が出ています
寸法・断層のボタンが押せない2D 表示で、高さマップがあるデータのときに使えます。点群形式 CSV では使えません
後処理の区画が出ない高さマップが無いデータ（点群形式 CSV）では出ません
three.js で回転が 2 種類とも同じthree.js では「ターンテーブル」と「自由回転」は同じ動きです
測定履歴が消えた履歴はブラウザごとの保存です。別のブラウザ・別の PC、またはブラウザのデータを消すと見えなくなります。残したい結果は CSV で書き出してください
「未保存（この回だけ）」と出るブラウザの保存容量が足りません。測定結果タブで古い履歴を削除してください
画面が重いエンジンを three.js にすると軽くなります。後処理や断層の帯は計算に少し時間がかかります

8.1用語

用語意味
