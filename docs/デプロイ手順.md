# デプロイ手順書 — Optical Device UI（Tori-Ton UI）

最終更新: 2026-09-07
対象読者: 本リポジトリの開発メンバー全員

本アプリは **クラウドには置かず、計測PC・展示PC のローカルで動かす** 構成です。
「デプロイ」とは、対象 PC 上で `main` を最新化し、依存関係・学習済みモデル・データを揃えて起動スクリプトで立ち上げることを指します。
コンテナ化・イメージレジストリ・stg/prod の環境分離は **現時点では採用していません**（§8 の今後の課題を参照）。

## 開発〜配備の全体フロー

```
main からブランチを切る（feature/... / fix/...）
  → ローカルで開発・確認（start_mac.sh / start_win.bat）
  → PR 作成 → CI（Prettier / ESLint / Build）が通る → approve → main へマージ
  → 対象 PC で main を pull（§4）
  → 依存関係・モデル・データを確認して起動（§5）
  → 起動後チェック（§6）
```

- 対象 PC へ持っていくのは **main にマージ済みのコミット** だけ。作業ブランチを直接 pull しない
- 展示会・デモの直前は、当日使う PC で **§6 のチェックを必ず前日までに一度通す**（モデルの取得や PyTorch の初回ロードに時間がかかるため）

## 1. 環境一覧

| | 開発機（各自） | 計測PC（社内） | 展示・デモPC |
|---|---|---|---|
| OS | macOS / Windows | Windows（CUDA GPU あり想定） | Windows または macOS |
| 起動 | `./start_mac.sh` / `start_win.bat` | `start_win.bat` | 同左 |
| 前処理 | CPU（CuPy 無し） | GPU（CuPy あり）または CPU | CPU で可（CSV 読込表示が主） |
| AI推論 | CPU / MPS / CUDA（自動判定） | CUDA | 不要な場合が多い |
| 用途 | 開発検証 | 実計測・評価 | 3D 表示・自動回転のデモ |

- フロントエンドは Vite の dev サーバー（<http://localhost:5173>）、バックエンドは uvicorn（`0.0.0.0:8000`）で動く。**本番ビルド（`frontend/dist`）はバックエンドから配信されていない**ので、現状はどの環境でも `npm run dev` 経由で起動する
- フロントは `ws://<アクセス元ホスト名>:8000/ws` に接続する。同一 LAN の別端末から見る場合は、対象 PC のホスト名または IP で 5173 番を開けばよい（8000 番も通しておくこと）
- 別端末から開く場合、`vite.config.ts` の `server.host` は未設定なので `npm run dev -- --host` で起動する（起動スクリプトは localhost のみ）

## 3. 初回セットアップ（対象 PC で 1 回だけ）

### 3-1. clone

```bash
git clone https://github.com/0122POND/optical-device-ui.git
cd optical-device-ui
```

### 3-2. 依存関係

```bash
# ルート（husky / lint-staged。配備のみの PC でも prepare が走るので実行しておく）
npm install

# フロントエンド
cd frontend && npm install && cd ..

# バックエンド
pip3 install -r backend/requirements.txt
```

- `backend/requirements.txt` は **AI 推論用の torch / segmentation-models-pytorch / transformers も含む**（サイズ大）。前処理と CSV 表示だけの PC でも requirements どおり入れておくのが安全（`ai_inference.py` は AI ボタン押下時に遅延 import されるので、入っていなくても起動自体はできる）
- GPU 前処理を使う PC のみ CuPy を追加する。**CuPy が無い状態で UI の GPU モードを選ぶと `ModuleNotFoundError: cupy` で処理が失敗する**（フォールバックは無い）。既定は CPU モード

```bash
pip install cupy-cuda11x   # CUDA 11.x
pip install cupy-cuda12x   # CUDA 12.x
```

- Windows で `pip install -r` が cp932 エラーを出す場合があったため、requirements.txt のコメントは英語に統一してある。日本語コメントを足さないこと

### 3-3. 学習済みモデルの配置

AI 推論（「AI計測」ボタン）に必要。`backend/models/` に `.pth` を置く。**git には含まれない**ので、USB か社内共有から手動でコピーする。

| UI の選択肢 | ファイル名 | 備考 |
|---|---|---|
| U-Net++ (ResNet50) | `best_model_resnet50.pth`（約 590MB） | **現在 UI で選べる唯一のモデル。必須** |
| （UI 非公開） | `best_model_resnet34.pth` ほか `ai_inference.py` の `MODEL_CONFIGS` 参照 | 評価用。無くてもよい |

- 元ファイルの出どころは学習リポジトリ `line-finder-ai` の `model/<arch>/best_model.pth`。**リネームして**置く（`MODEL_CONFIGS` の `checkpoint` と一致させる）
- 置き場所を間違えると AI 推論開始時にファイル未検出で失敗する。`/health` は通るので、起動確認だけでは検出できない

### 3-4. データの配置

```
data/
├── row_data/      # 入力画像 img_001.bmp, img_002.bmp, ...（前処理・AI推論の入力）
├── result/        # 前処理結果（自動生成）
└── mask_result/   # AI推論結果（自動生成、manifest.json はサーバーが自動生成）
```

- `data/` は丸ごと `.gitignore`。対象 PC に別途コピーする
- ファイル名は `img_NNN` 形式で、3 桁と 4 桁が混在するとソートが辞書式にならない点に注意（サーバー側は自然順ソートで読む）
- 展示・デモで CSV を読み込ませる場合は、`1円玉裏_stitched_20260709.csv` のような Keyence 互換 CSV（-9999.9 = 欠損）を UI の CSV 読込から開く。ファイルの置き場所は任意

## 4. 更新の反映（main を pull）

```bash
cd optical-device-ui
git switch main
git pull

# package.json / package-lock.json が変わっていたら
cd frontend && npm install && cd ..
# backend/requirements.txt が変わっていたら
pip3 install -r backend/requirements.txt
```

- 対象 PC 上で **コードを直接編集しない**。直したいことがあれば開発機で PR にする
- `git status` が汚れていたら（展示直前の応急処置など）、内容を確認してから `git stash` か破棄してから pull する

## 5. 起動と停止

| OS | 起動 | 停止 |
|---|---|---|
| macOS / Linux | `./start_mac.sh` | `./stop_mac.sh` または Ctrl+C |
| Windows | `start_win.bat` をダブルクリック | `stop_win.bat` |

- 起動スクリプトは 8000 / 5173 番の残存プロセスを kill してから、uvicorn（バックグラウンド）→ Vite の順に起動し、3 秒後にブラウザを自動で開く
- UI 右上の**終了ボタン**は `POST /shutdown` を叩き、サーバー側が OS を判定して `stop_mac.sh` / `stop_win.bat` を実行する。ブラウザからでも完全停止できる
- 手動で起動する場合（ログを分けて見たいとき）:

```bash
# ターミナル1
cd backend && python3 -m uvicorn app:app --host 0.0.0.0 --port 8000
# ターミナル2
cd frontend && npm run dev
```

- **`python app.py` では起動しない**（`app.py` に `__main__` が無い）。CLAUDE.md の古い記載に注意

## 6. 起動後チェック

対象 PC に配備したら、少なくとも以下を通す。

```bash
curl -s localhost:8000/health     # {"ok":true}
```

1. <http://localhost:5173> が開き、ヘッダーとサイドパネルが表示される（縦解像度が低い PC では下部が見切れないことを確認）
2. 前処理: `data/row_data/` を置いた状態で CPU モード・「硬貨」で START → 進捗バーが進み 3D 点群が出る
3. AI 推論（使う PC のみ）: 「AI計測」→ U-Net++ (ResNet50) で完走し、マスク由来の点群が出る。初回はモデルロードに時間がかかる
4. CSV 読込: 表示用 CSV を読み込み、Surface / 点群（three.js）表示、断層出力、距離計測、2D 寸法測定を一通り触る
5. 展示・デモ PC のみ: 自動回転を ON にして 1 周（約 24 秒）以上放置し、画面がスリープしない（Wake Lock）ことを確認する。**Wake Lock はブラウザタブが前面にあるときだけ効く**ので、フルスクリーンで置く
6. 終了ボタンで両プロセスが落ちることを確認する

## 7. ロールバック

コード起因の不具合で戻したいときは、対象 PC で直前の正常コミットへ戻す。

```bash
git log --oneline -10                 # 正常だったコミットを特定
git switch --detach <コミット>          # 一時的に戻す（main は触らない）
# 依存関係が変わっていれば npm install / pip install をやり直す
./start_mac.sh  # または start_win.bat
```

復旧後は開発機で修正 PR を出し、マージ後に `git switch main && git pull` で追従する。タグ運用は未導入なので、展示会などの節目では **使ったコミットハッシュをメモに残す**こと。

## 8. 決定済み事項と今後の課題

決定済み:

- ローカル起動のみ。外部公開しない前提のため、CORS `allow_origins=["*"]` や `/data/result/{filename}` の入力検証未実装は許容している（外部公開する場合は先に対処する）
- 展示会向け機能は「自動回転」のみ残す。「デモ再生（走査積み上げ）」は 2026-08-20 に不要と判断して削除済み（復活させる場合はコミット `00cb636` の diff を参照）
- AI モデルは `.pth` を手動配布する運用（サイズ 590MB・git 管理外）

未決・今後の課題:

- `frontend/dist` を uvicorn から配信する本番ビルド運用（現状は dev サーバー起動が前提）
- 配備用パッケージ化（Docker / pyinstaller 等）。PC ごとの CUDA 差異を吸収する手段が無い
- リリースタグの導入と、対象 PC ごとの配備履歴の記録

## 9. 既知の罠（ハマったら読む）

| 症状 | 原因と対処 |
|---|---|
| GPU モードで処理開始直後に失敗する | CuPy 未導入。§3-2 で CUDA に合う CuPy を入れるか、CPU モードを使う |
| AI 推論が「モデルをロード中」で失敗する | `backend/models/best_model_resnet50.pth` が無い、またはファイル名が違う（§3-3） |
| ブラウザは開くが「接続中」のまま | uvicorn が起動していない。8000 番の衝突か `pip install` 漏れ。ターミナルのバックエンドログを見る |
| 別端末から 5173 番に繋がらない | Vite が localhost のみ待ち受け。`npm run dev -- --host` で起動し、8000 番も開ける |
| Windows で起動スクリプトの文言が文字化けする | 既知。スクリプトは英語表記に統一済み。日本語を足さない |
| Windows で `pip install -r` が cp932 エラー | requirements.txt に日本語コメントが混入。英語に戻す |
| 前回のプロセスが残っていて起動できない | 起動スクリプトが自動 kill する。効かないときは `stop_*.sh/bat` を先に実行 |
| 展示中に画面がスリープする | 自動回転 ON 時のみ Wake Lock が効く。タブを前面・フルスクリーンにし、OS 側の省電力設定も切る |
| 起動直後の 3D が更新されない・挙動が古い | Vite の HMR が three.js の描画ループを古いまま掴むことがある。ページを完全リロード |
