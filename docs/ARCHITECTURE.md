# アーキテクチャ概要

このドキュメントでは、Optical Device UIのシステムアーキテクチャについて説明します。

## システム構成図

```
┌─────────────────────────────────────────────────────────────┐
│                        Browser                               │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              React Frontend (Vite)                   │   │
│  │  ┌───────────┐  ┌───────────┐  ┌───────────────┐   │   │
│  │  │  App.tsx  │  │  utils/   │  │  Plotly.js    │   │   │
│  │  │  (UI)     │  │  (処理)   │  │  (3D描画)     │   │   │
│  │  └─────┬─────┘  └───────────┘  └───────────────┘   │   │
│  └────────┼────────────────────────────────────────────┘   │
│           │ WebSocket                                        │
└───────────┼─────────────────────────────────────────────────┘
            │
┌───────────┼─────────────────────────────────────────────────┐
│           ▼                                                  │
│  ┌─────────────────┐     ┌──────────────────────────┐      │
│  │  FastAPI        │────▶│  preprocess_images.py    │      │
│  │  (WebSocket)    │     │  (画像処理)              │      │
│  └─────────────────┘     └──────────────────────────┘      │
│                     Python Backend                           │
└─────────────────────────────────────────────────────────────┘
```

## コンポーネント詳細

### フロントエンド

| コンポーネント | 責務 |
|--------------|------|
| `App.tsx` | UIレイアウト、状態管理、WebSocket通信 |
| `utils/surface.ts` | 3Dサーフェスデータ生成 |
| `utils/pointCloud.ts` | BMP画像から点群データ構築 |
| `utils/stream.ts` | 点の漸進的レンダリング |
| `utils/csv.ts` | CSVエクスポート |

### バックエンド

| コンポーネント | 責務 |
|--------------|------|
| `backend/app.py` | WebSocketサーバー、コマンド処理 |
| `scripts/preprocess_images.py` | 画像前処理（背景差分、ピーク検出） |

## データフロー

```
1. ユーザーが「START」クリック
        │
        ▼
2. WebSocketで "preprocess" コマンド送信
        │
        ▼
3. バックエンドが画像処理を実行
   - 背景差分
   - ガウス窓適用
   - ピーク検出
        │
        ▼ (進捗をWebSocketで随時送信)
        │
4. 処理完了、結果画像を保存
        │
        ▼
5. フロントエンドが結果画像を読み込み
        │
        ▼
6. 点群データを生成してPlotly.jsで3D描画
```

## 技術選定理由

| 技術 | 選定理由 |
|------|---------|
| **React** | コンポーネントベースのUI構築、豊富なエコシステム |
| **TypeScript** | 型安全性による開発効率向上、IDEサポート |
| **Vite** | 高速な開発サーバー、HMR対応 |
| **Plotly.js** | インタラクティブな3Dグラフ、WebGL対応 |
| **FastAPI** | 高性能、WebSocket対応、型ヒント活用 |
| **WebSocket** | リアルタイム双方向通信、進捗表示に最適 |

## ディレクトリ構造の設計意図

```
optical-device-ui/
├── frontend/          # フロントエンド（独立してビルド可能）
├── backend/           # バックエンド（Python単体で実行可能）
├── scripts/           # 再利用可能なスクリプト
└── docs/              # ドキュメント
```

- **フロントエンド/バックエンド分離**: 独立したデプロイ、スケーリングが可能
- **scripts分離**: CLIツールとしても利用可能
